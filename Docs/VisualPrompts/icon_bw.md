# Grayscale Icon Workflow

## Prompts

### Prompt 1: Ideas

> Generate 30 ideas for a Rimworld icon that represents `your requirement here`.

### Prompt 2: Icon Sheet

In the same chat. If you are having trouble then cut-and-paste only the suggestions you like into a new chat.

> A crisp digital vector sheet on a pure chroma key greenscreen (#00FF00) background, displaying a precise and symmetrical 10x10 grid of black-and-white, hand-drawn icon variations. Each small icon adheres to a minimal line art style with a uniform thick, heavy black outline and flat colors like a vector drawing. The edges of every icon are perfectly sharp and aliased, with zero dithering, bleeding, or anti-aliasing artifacts between the black lines and the green background. Make the exterior black outlines an extra 5px bigger. The composition features 100 unique variations, showcasing a diverse range of interpretations of the icon description. Rows 1 through 5 present variations that try to stick to the icon prompt in different styles. Rows 6 through 10 introduce variations to the icon prompt that make sense but use creativity to explore ideas that weren't in the original prompt. The entire grid is perfectly clean, organized, flat, and technical, focusing solely on the subtle differences within the icon designs. No duplicates! Include cell-shading.

### Pick an icon and use it for a new chat

`Windows Key+Shift+S` to cut and `Ctrl+V` in the new chat.

### Clean it up

Download the image, crop it, load it in paint.net, use the magic wand to set the transparency and resize it.
